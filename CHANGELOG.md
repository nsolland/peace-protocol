# Changelog

All notable normative changes to the PEACE Protocol are recorded here.

## 0.1.0-draft.1 — publication candidate

Status: unreleased.

Initial dedicated-repository publication candidate establishing:

- PEACE world contract and derivation question;
- core sovereign-domain invariants;
- `Framleis` continuity principle;
- actor/state/standing/authority separation;
- governed disclosure;
- candidate != decision;
- no direct effect path;
- fresh exact consequence authorization;
- evidence != authoritative state;
- routing != authority;
- settlement as governed consequence;
- replica != sovereign;
- recovery != identity transfer;
- vendor-neutral protocol/implementation separation;
- public envelope schema and conformance vectors;
- Apache-2.0 licensing policy;
- governance, contribution, security and trademark/compatibility policies;
- publication plan and release discipline.

### Lineage

The first public PEACE proposal seed appeared in `nsolland/reht-standard` PR #21 before creation of this dedicated repository. That proposal remains historical lineage and is not normative REHT material.

### Release rule

This version is not published until an immutable `v0.1.0-draft.1` tag points to the exact validated release head and release notes identify it as a draft/prerelease.
